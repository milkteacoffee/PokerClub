🎁 任务与成就

小馆内含德州扑克、21点、炸金花、3/5骰 · 多项下注。大厅选择游戏再点击开始；新游戏提供金币场与免费练习，练习筹码可补满但不可兑换。任务、成就和排位仍为德州专属，新游戏战绩在各自牌桌查看。新游戏未完局刷新或离桌视为放弃已投入筹码。

小游戏的操作按牌桌习惯收拢：下注金额在顶部用筹码点选，骰子直接点押注格下注，炸金花的“比牌”按钮落在对手座位上，骰子出目后自动开奖结算。每局结束会显示大字输赢与明细，主按钮直接变成“再来一局”，金额保持不变。

每日5项，每项40金币，每天最多200；每周一刷新25项，按阶段奖励30至78金币，每周最多1242；每月1号刷新10项月度挑战，共4000金币。成就共1000项，按进阶目标解锁，单项10至2000金币，需在成就页领取。日周月刷新以北京时间为准。

任务与成就列表里，已完成但还没领奖的条目会自动排到最上面，其次是进行中的，已领取的沉到列表底部。任务、每日、周常、签到与成就面板顶部都有一键领取按钮，一次领完当前可领的全部奖励；成就的一键领取会连同还没翻到的分页一起结算。

新手场每手开局至少500金币。电脑对手低于500时在下一手前离桌，由新昵称对手带入500补位；玩家不足500会保留余额返回大厅。对手昵称随机生成，仍全部为本地电脑AI，不是真人联机。

每手使用全新52张牌，安全随机洗牌，不按输赢安排牌型；正常随机可能连续出现相同点数或弱牌。

单机模式不登录、不联网，数据保存在本机浏览器；使用「好友开房」时会连接自建服务器（用于同步房间状态与好友资料），此时会保存昵称、签名、头像与对局记录，不收集与游戏无关的信息、不做用户画像。同 Wi-Fi 不同设备互不影响。清除网站数据会丢失本机存档，可用「玩家号 + 恢复码」在新设备接管云端存档。旧版存档保留只读导出。

🏅 段位排位

本游戏为单机电脑对战，无真人匹配。快速模式不影响段位；排位入场前需资产至少 10,000 金币，每次入场消耗 1 排位积分（初始 100，可在模式页用 100 金币购买 1 分），继续下一手不重复收门票。

段位积分与入场积分独立：每个游戏有自己的段位阶梯（德州「牌桌新人 → 读牌学徒 → 老练牌手 → 心理读牌师 → 气场宗师 → 牌桌枭雄 → 德州王牌」，21点「点数学徒 → … → 二十一之神」，炸金花「闷牌新手 → … → 金花炸王」，猜骰子「骰盅学徒 → … → 心眼财神」，骰子比大小「掷骰新手 → … → 神手骰王」，掼蛋「掼蛋新手 → … → 掼蛋的神」）。胜手 +12 至 +26，三连胜起额外 +2；弃牌失利 -5，摊牌失利 -10，最低 0 分，可降段。各段位金币奖励仅首次到达发放。

大厅直接点击用户名改名，回车或点击别处保存，Esc 取消。每手结算可在桌底回看；中途离桌保留剩余筹码、放弃本手已投入筹码，排位另扣最多 5 段位分。离桌汇总区分牌局盈亏、入场费和奖励收入。
